# Evidence Log — Feature 002 Reference Inspection

Every fact in this baseline resolves to an evidence id below. Nothing here comes from model memory,
third-party blogs, review sites or comparison articles.

**Verification types**

| Type                 | Meaning                                                                                                                     |
| -------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| `LIVE_DOM`           | The surface was rendered in an authenticated reference session and read from the live DOM or accessibility tree.            |
| `LIVE_MEASURED`      | A value was read from computed styles or element geometry in the live DOM. The viewport is stated.                          |
| `OFFICIAL_DOC`       | An official documentation or Help Center page of the reference vendor was opened and read.                                  |
| `OFFICIAL_MARKETING` | An official vendor product/marketing page was opened. Weaker than `OFFICIAL_DOC`; never used alone for a behavioural claim. |
| `ACCESS_PROBE`       | A navigation attempt made to establish whether a surface is reachable at all.                                               |

Timestamps are the completion time of the inspector run that produced the evidence. All runs were
executed on 2026-08-30 (UTC) by the `reference-inspector` worker over the `OMA References` Chrome
profile. Raw transcripts are retained locally in `.reference/002-evidence/` and are git-ignored.

Screenshot paths: **none**. Screenshot capture was not available in these sessions, so all evidence
is DOM, accessibility-tree, computed-style or documentation text. No image was captured and none is
committed.

## Evidence quality rules applied

- A page title alone was never accepted as proof of a capability.
- No screenshot was treated as proof of backend behaviour; no screenshot exists in this baseline.
- Documentation was never treated as proof of what happened inside the OMA-owned account. Where the
  live surface was gated, the status says `DOC_VERIFIED` and not `LIVE_VERIFIED`.
- A currently visible UI was never treated as proof of an untested permission. Every permission
  claim in `06-role-permission-matrix.md` names its evidence, and unproven ones stay `UNKNOWN`.
- Model memory was not used as evidence anywhere.
- Statements that go beyond what was read are labelled `INFERENCE` at the point of use.
- Unknowns stay `UNKNOWN` rather than being resolved by reasoning.
- Because Jasper is documentation-only and Semrush's live product was subscription-gated, this
  baseline does not claim complete coverage. See `08-coverage-summary.md`.
