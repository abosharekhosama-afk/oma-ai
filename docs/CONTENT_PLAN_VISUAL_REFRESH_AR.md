# تسليم تحديث واجهة خطة المحتوى

## النطاق

تحديث بصري محدود لسطح Content Plan في مشروع OMA AI، مستند إلى صور Planable المرفقة ومواصفات `DEC-017` و`PLANABLE_COMPONENT_SPEC` و`PLANABLE_DESIGN_TOKENS_SPEC` و`PLANABLE_RESPONSIVE_SPEC`.

لا يغيّر هذا التحديث قواعد العمل أو مصادر الحقيقة: حفظ المسودة منفصل عن الجدولة، التاريخ المخطط لا ينشر المحتوى، وسياسات الاعتماد تبقى `NONE` و`OPTIONAL` و`REQUIRED`. حالة النشر الخارجي والذكاء الاصطناعي غير المتصل تبقى واضحة.

## التعديلات

- إخفاء زر الإنشاء العام الذي يكرر زر إنشاء المحتوى ويقود إلى مسار الطلبات، وذلك في صفحات المحتوى فقط.
- نقل البحث المتقدم من شريط مزدحم إلى لوحة فلاتر جانبية، مع تثبيت أزرار التطبيق والمسح في تذييلها. تنتقل اللوحة إلى الحافة المقابلة في RTL وتملأ الشاشة على الهاتف.
- تحسين الحالة الفارغة بنص مستقل لخطة فارغة ونص آخر لنتيجة بحث/فلاتر فارغة؛ لا تستخدم صورة أو أصلًا مملوكًا لمرجع خارجي.
- توسيع نموذج إنشاء المحتوى على الشاشات الكبيرة وترتيب حقوله في عمودين، ثم إعادته إلى عمود واحد على الهاتف.
- تحديث اختبارات رحلة الفلاتر لتتبع مكان البحث الجديد وتذييل اللوحة.

## حدود التحقق

هذه حزمة مصدر محلية مستخرجة من ZIP وليست نسخة Git متصلة؛ لذلك لم يُفحص سجل CI عن بُعد ولم تُنشأ معاينة حية أو مقارنة بكسلية جديدة مع جلسة Planable. لا يُعد هذا التغيير إغلاقًا لـ`GOLDEN_CONTENT_PLAN` أو قبولًا بصريًا.

اجتاز التحقق المحلي تنسيق Prettier للملفات المعدّلة، وفحص صياغة TypeScript/TSX لسبعة ملفات، وصحة JSON وتطابق مفاتيح اللغتين (1001 مفتاحًا لكل لغة). فشل تثبيت الاعتماديات بسبب HTTP 403 من سجل الحزم الداخلي عند تنزيل `tinypool@1.1.1`؛ لذا لم تُشغّل فحوص TypeScript الكاملة أو ESLint أو Vitest أو Playwright.

المستندات المرفقة تتضمن أحكامًا تاريخية متعارضة حول حالة الشاشة الذهبية؛ تُتبع ملاحظات التسليم الأحدث المرفقة مع الطلب، وتبقى حالة القبول بحاجة إلى التحقق داخل المستودع والبيئة الحية المعتمدين.
