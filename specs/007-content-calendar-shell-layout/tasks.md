# المهام — إصلاح استجابة تقويم المحتوى والهيدر

- [x] **T1 — تخطيط شريط التقويم والـ popover:** جعل شريط التقويم داخل تدفق عمود المحتوى وبطبقة أدنى من rail؛ ربط قائمة العرض بموضع breadcrumb (مع بديل لزر التبديل عند إخفاء المسار بالهاتف)، وإعادة حسابها عند resize/scroll/تغير عرض العمود أو حالة rail، مع احترام LTR/RTL. اختبار الوحدة يغطي هذه العقود. قبول مرتبط بـ FR-001 وFR-002.
- [x] **T2 — ضغط مسار الهيدر:** فرض سطر واحد قابل للانكماش، مع ellipsis للنصوص وتثبيت مساحة الإجراءات. اختبار الوحدة وفحص TypeScript لواجهة الويب نجحا؛ المراجعة البصرية لمقاسات العرض ما زالت ضمن T4. قبول مرتبط بـ FR-004.
- [x] **T3 — ارتفاع خلايا المحتوى وهوامش الفلترة:** ضبط صفوف الشهر إلى 260px (220px compact) وخلايا الأسبوع إلى 220px (200px compact)، مع الإبقاء على حد بطاقتين وطريقة الوصول للعناصر الزائدة الموجودة. إضافة حشوة داخلية 16px للوحة وإزالة الهوامش الخارجية للصفوف. اختبار الوحدة يغطي القواعد؛ تحقق ظهور البطاقات بصريًا ما زال ضمن T4. قبول مرتبط بـ FR-003 وFR-005.
- [ ] **T4 — إثبات عدم التراجع والمزامنة:** اختبارات Vitest ذات الصلة نجحت (16 اختبارًا)، وفحص `@oma/web` TypeScript نجح، وPrettier و`git diff --check` نجحا. بقيت مراجعة EN/AR وLTR/RTL و1440×900 و1024×768 و390×844 وPlaywright؛ لم تُشغّل لأن إعداد قاعدة `oma_ai_e2e` وخدماتها لم يُثبت توفرها. كما فشل `pnpm typecheck` الشامل في `@oma/db` بسبب مراجع/تصديرات Prisma غير المتاحة، لا في ملفات الواجهة المعدلة. قبول مرتبط بـ FR-006 ومعايير القبول 1–7.
